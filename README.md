# lms-database
Проектирование базы данных для LMS-платформы с курсами, уроками и тестами

LMS Database Design
📌 Описание проекта

Система предназначена для хранения и управления обучающим контентом:
симуляторы (курсы), главы, шаги (текст, видео, вопросы, диалоги), а также тесты и ответы пользователей.

Реализованы:
- иерархия "симулятор → глава → шаг"
- разные типы шагов через отдельные таблицы
- система тестов с вариантами ответов
- хранение ответов пользователей
- поддержка SEO-страниц

База спроектирована с учетом нормализации и возможности расширения.

🧩 Основные сущности
Simulators — обучающие курсы
Chapters — главы внутри курса
Steps — шаги внутри главы (текст, видео, вопрос, диалог)
Questions & Answers — тестовые задания
Users & User Answers — ответы пользователей
Pages — SEO и URL страниц

🔗 Связи
Один симулятор → много глав
Одна глава → много шагов
Один шаг → один тип контента (text / video / question / dialog)
Один вопрос → много ответов

🛠 Структура проекта
create_tables.sql — создание таблиц
insert_sample_data.sql — тестовые данные
queries.sql — примеры запросов 
schema.drawio — схема базы

🚀 Как запустить
Создать новую базу данных (например, в DBeaver)
Запустить create_tables.sql
(опционально) Запустить insert_sample_data.sql
Выполнить SELECT-запросы для проверки

💡 Особенности
Нормализованная структура
Использование внешних ключей
Расширяемая архитектура (новые типы шагов добавляются без изменений схемы)
